OH MY GRACIOUS - PRE-PAYMENT OPERATIONAL UPGRADE
Version: 3.1-half1-real-services

IMPORTANT: BACK UP BOTH PROJECT FILES AND THE MYSQL DATABASE BEFORE UPGRADING.

EXISTING INSTALLATION (your current XAMPP project)
1. Stop editing the old project while upgrading.
2. Back up C:\xampp\htdocs\oh_my_gracious.
3. Export the current oh_my_gracious database from phpMyAdmin.
4. Copy this upgraded project over the existing project folder.
   - Keep your existing .git folder if you use Git.
   - DO NOT copy/commit a real .env to GitHub.
5. If you do not already have .env, copy .env.example to .env.
6. Confirm the previous capacity/Google migration was already applied. Then in phpMyAdmin, select oh_my_gracious and run ONCE:
   database/migrations/2026_10_real_services_frontdesk_lockdown.sql
7. Open:
   http://localhost/oh_my_gracious/tools/health-check.php
8. Confirm all required database tables show green checks.
9. Test email/password login, Google login (after configuring GOOGLE_CLIENT_ID), customer booking, front desk, availability controls, owner settings, AR, and manual payment status.

FRESH INSTALLATION
1. Create an empty database named oh_my_gracious.
2. Import database/production_schema.sql.
3. Copy .env.example to .env and set local DB settings.
4. Open tools/create-owner.php in local mode to create the first owner account.
5. Open tools/health-check.php.

AUTHENTICATION IN THIS BUILD
- Email/password: enabled
- Google registration/login: enabled after GOOGLE_CLIENT_ID is configured
- Facebook registration/login: removed
- Phone/SMS registration/login: removed
- A phone number is still kept as normal customer contact information.
- Google identity + verified email duplicate safeguards prevent duplicate customer accounts.

BOOKING MODEL IN THIS BUILD
- Fixed appointment times: 9 AM, 10 AM, 11 AM, 1 PM, 2 PM, 3 PM, 4 PM, 5 PM, 6 PM, 7 PM
- Capacity per time slot (default 5, owner configurable)
- Front desk can close/open a specific date/time or override capacity
- Front desk can temporarily disable a service with a reason
- Estimated service duration is informational only
- Multiple services per appointment remain supported
- Real salon catalog/prices are seeded from the supplied menu photos
- Owner can edit fixed, per-nail, and range prices
- Per-nail services support 1-10 nail quantity
- Front Desk booking creation is disabled; customers create their own appointments

PAYMENTS
- Online payment integration is intentionally NOT active yet.
- Current method: Pay at Salon / Cash
- Front desk can mark an eligible appointment Paid and print a receipt.

GOOGLE SETUP
In .env:
GOOGLE_CLIENT_ID=YOUR_WEB_CLIENT_ID.apps.googleusercontent.com

Create a Google OAuth Web Application client and add your local/public authorized origins.
For localhost, use the exact origin that matches your APP_URL, for example:
http://localhost

Before public deployment, use HTTPS, production DB credentials, a real mail transport for password-registration email verification, and remove/disable local setup tools.

OH MY GRACIOUS - VERSION 3.0 PRE-PAYMENT

Core roles
- Customer (user)
- Front Desk / Receptionist (admin)
- Owner / Manager (super_admin)

Authentication
- One login page for all roles
- Email/password registration/login
- Google registration/login using Google Identity Services
- Google duplicate prevention by provider ID + verified email + DB unique constraints
- New Google accounts forced to customer role
- No Google auto-linking to privileged staff/owner accounts
- Facebook authentication removed
- Phone/SMS authentication removed
- Phone number retained only as contact information

Booking operations
- Multiple services in one appointment
- Server-side service price calculation
- Fixed booking times: 9, 10, 11 AM and 1-7 PM
- Configurable capacity per time
- Transactional capacity reservation
- Fully booked / closed / passed time handling
- Front desk daily slot close/open and capacity override
- Front desk service availability control with reason
- Estimated duration informational only
- Existing-customer and guest/walk-in front-desk booking
- Front-desk reschedule, approve, reject, cancel, no-show, check-in, complete

Payments
- Pay at Salon / Cash only in this release
- Manual front-desk Paid status + printable receipt
- Online payment integration intentionally removed/deferred

Owner
- Revenue summaries from recorded Paid transactions
- Service category/name/price/duration catalog
- Technician management
- Admin account management
- Fixed slot/default capacity settings
- Audit logs

Security / deployment foundations
- Role authorization
- CSRF
- password_hash/password_verify
- prepared statements
- login rate limiting
- secure session configuration
- server-side price validation
- .env excluded from package/Git
- no public admin registration
- no hard-coded production credentials
